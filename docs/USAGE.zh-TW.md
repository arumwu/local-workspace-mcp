# 使用說明：用一般 ChatGPT 對話操作自己的電腦

[English](USAGE.en.md) · [第一次安裝與連線](CHATGPT.md) · [專案首頁](../README.md)

這份說明適用於已完成安裝、已在 ChatGPT 連接 `Local Workspace MCP` 的使用者。
你在 ChatGPT 下指令，私人通道把工具請求送到你的電腦，由電腦實際讀取檔案、處理文件與執行 Python。
一般 ChatGPT「對話」就是主要入口，不必開啟 Codex 或切換 Work。

## 我的電腦需要一直開著嗎？

**需要用本機工具時，執行 MCP 的電腦必須開機、保持喚醒並連上網路。**
私人通道提供連線，不會把你的電腦或執行環境搬到雲端。

| 電腦狀態 | 能不能使用本機工具？ |
|---|---|
| 已開機、登入、保持喚醒，通道正常運作 | 可以發送工具請求 |
| 只有螢幕關閉或鎖定，但電腦沒有睡眠 | 不會僅因螢幕關閉就停止；仍需網路、磁碟與程序正常 |
| 電腦睡眠、關機、斷網，或通道停止 | 無法正常執行本機工具 |
| 電腦重開機，但還沒登入 | 本教學安裝的登入服務尚未啟動 |
| 工具或檔案位於外接碟，外接碟未掛載 | 無法使用依賴該磁碟的功能 |
| Docker 未啟動 | `run_python` 無法使用；其他本機工具不一定受影響 |

不使用工具時可以關機。普通 ChatGPT 對話不因此停用，但它不能繼續操作離線電腦的檔案。
這個安裝不提供遠端喚醒，也不會替你更改睡眠設定。

## 電腦與手機怎麼用？

1. 在要使用的裝置登入**同一個 ChatGPT 帳戶與工作區**。
2. 開啟一般「對話」，在可用的外掛選單選擇 `Local Workspace MCP`，或在訊息中指定它。
3. 說明檔案位置、要做的事、產出要存哪裡；第一次先做下方連線測試。

**手機是下指令的介面，真正工作的是那台電腦。**
若手機 ChatGPT 介面已提供這個自訂外掛，就能走同一條私人通道，不需要把 Python、Docker 或 MCP 裝在手機上。
通道透過網際網路連線，架構上不要求手機和電腦使用同一個 Wi-Fi；雙方仍須能連上相關服務。

手機 App、手機瀏覽器與桌面 App 的外掛功能可能不同。若手機找不到外掛，不能只憑「帳號相同」認定已接通。
請以該裝置**實際呼叫工具成功**為準，不保證所有 App 版本、帳號與工作區都支援。
本專案已實測一般 ChatGPT 網頁對話；手機及原生桌面 App 尚未由維護端獨立實測。

## 第一次先貼這段

> 請使用 Local Workspace MCP，先呼叫 get_workflow_instructions，再用 run_python 執行 print('LOCAL_MCP_OK')。不要使用內建 Python 代替，不要讀寫其他檔案。請回報實際工具名稱、stdout 與 exit code。

真的成功時，應有該外掛的工具呼叫，stdout 為 `LOCAL_MCP_OK`、exit code 為 `0`。
只回覆「已安裝」、列出範例程式或使用 ChatGPT 內建 Python，都不算驗證成功。

## 平常可以怎麼說？

**查看檔案：**

> 使用 Local Workspace MCP，列出「我的資料夾完整路徑」第一層的檔案，先不要修改。

**處理報表：**

> 使用 Local Workspace MCP，讀取工作資料夾裡的 sales.csv，整理每月總額，產生 Excel 與長條圖，核對總額後告訴我產出位置。

**製作文件：**

> 使用 Local Workspace MCP，把 notes.md 整理成 Word 和 PDF。保留原稿，另存新檔，檢查內容後告訴我儲存位置。

**修改既有文件（完整模式）：**

> 使用 Local Workspace MCP，先備份這份文件，再依我的要求修改。完成後重新讀取確認，不要改動其他檔案。

使用檔案的完整路徑，避免只說「桌上那份」或「剛剛那個」。
`run_python` 的隔離環境只能讀取指定工作資料夾；完整模式的主機工具才負責其他獲准位置的檔案。
完整模式能以目前使用者權限修改檔案、執行程式與連網，資料夾清單不是安全沙盒。

## 產出會在哪裡？手機可以下載嗎？

Docker 文件工作的產出預設放在**電腦上的工作資料夾／exports**。
手機看得到回覆，不代表檔案已傳到手機；`/Volumes/...`、`/Users/...` 是電腦本機路徑。

目前私人 STDIO 通道不會自動把產出變成 ChatGPT 附件或公開下載連結。
若要在手機取用，需另外透過你同意的傳檔方式分享；不要把「檔案已生成」誤認為「手機已能下載」。

## 登入自啟與停止

macOS 若已安裝登入服務，登入後會啟動通道。中文教學使用的名稱是 **「ChatGPT 本機工具」**；
英文預設名稱是 `ChatGPT Local Workspace MCP`。它會保持必要的背景程序，不是零記憶體用量。
Docker Desktop 需另行保持運作；本工具不會替你啟動 Docker。

要暫時停止，可以在 macOS 背景項目停用自己安裝的這個項目，或依[安裝教學](CHATGPT.md#5-macos-登入後自動啟動)停止服務。
在 ChatGPT 斷開外掛可停止該帳戶連線，但不等於電腦上的背景程序也會停止。
不要為了清理 MCP 而刪除用途不明的其他 `sh`、`open` 或背景項目。

## 找不到工具或執行失敗

依序檢查：電腦已登入且醒著 → 網路與外接碟正常 → 通道已啟動 → ChatGPT 帳戶／工作區正確 → 外掛已連線。
若只有 `run_python` 失敗，再檢查 Docker 是否運作。
修復後開新對話，重做 `LOCAL_MCP_OK` 測試；不要反覆安裝造成多份常駐程序。

官方連線原理與條件：[OpenAI Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)。
